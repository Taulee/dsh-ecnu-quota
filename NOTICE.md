# 第三方出处与许可

## dsh-qoder-connect

本项目的界面与交互设计对齐自 **dsh-qoder-connect**：

- 仓库：https://github.com/masknull/dsh-qoder-connect
- 作者：corrinehu
- 许可：MIT

沿用其额度卡片的版式（侧边栏底部常驻卡片 / 折叠态圆环按钮 / 明细面板）、配色令牌（`--dsw-alias-*`）、圆环与进度条画法，以及「剩余 / 占本轮总额度 / 本轮已用」这套文案结构。原项目的额度取得、签到、模型目录等功能均未引入，本项目只借用展示层设计。
